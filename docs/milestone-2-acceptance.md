# Milestone 2 acceptance

Milestone 2, "headless mock lifecycle and context inspection", closes when
every criterion points at tests that pass and every gap is written down. This
table maps the criteria of the [roadmap](roadmap.md), section 2,
and the RFC-001 cases it names (M01–M04, C01, R02, E01) to tests, as of
2026-10-22. Test names are Rust test functions; `runtime::tests` scenarios
each run twice, are replayed byte for byte, are resync-checked from every view
and end with every started turn finished exactly once.

Update 2026-10-29: [Milestone 3 acceptance](milestone-3-acceptance.md) closes
R02's approval/execution cancellation remainder. The dated table below preserves
the original Milestone 2 scope.

Status: **met** means the criterion is covered as Milestone 2 scopes it;
**partial** means part of it depends on something Milestone 2 does not build,
and the note says what and where it goes; **gap** means in scope and not
covered. There are no gap rows.

## Running the evidence

```sh
CARGO_NET_OFFLINE=true ./scripts/check.sh
RUNTIME_SEEDS=5000 cargo test --release -p harness-core --locked randomized -- --nocapture
cargo run --locked -p harness-core --example scripted_session
```

`check.sh` runs 512 randomized seeds; the 5,000-seed run is a manual release
check that prints the paths it reached, including crashes, repairs,
resolutions by kind and turns closed by recovery.
